#### Smart Home Control Panel (Desktop Simulator)

Designed and developed a desktop-based GUI simulation of a smart home control system using Python and Tkinter. The application allows users to interact with simulated smart devices (lights, fans, thermostat, security system) in real time, with features like:

Room-wise control using tabbed interfaces
Real-time toggles and temperature dials
Authentication system with login/logout
Theme switcher (light/dark mode)
Data visualization for energy usage and device activity
Simulated MQTT-based communication and multithreading


###### Skills & Tools:
Python, Tkinter, OOP, Modular Design, Multithreading, MQTT (simulated), Data Visualization (matplotlib/tkCanvas), Authenticatio
